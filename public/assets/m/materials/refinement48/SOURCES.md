# Blender refinement 48 materials

Authored locally in Blender 4.5.14 on 2026-10-01. Procedural, deterministic 512 x 512 PNG maps for honed limestone, oiled teak and woven linen. Each set includes colour (sRGB), roughness (linear) and tangent-space normal (linear). No remote textures or paid generation services.

Editable material node trees and packed copies of all nine images are in `MSelect-web47-refinamento48.blend`. The Python generation source is preserved with that deliverable. Colour variation is decorative, not a specification for a commercial material.
